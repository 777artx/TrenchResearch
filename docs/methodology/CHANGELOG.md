# Methodology change log

Every change to a published formula, input, universe rule or data source is recorded here with its date and reason, and is marked on affected charts. Entries are never edited after the fact.

| Date | Change | Reason |
|---|---|---|
| 2026-11-17 | Project started. No indicators published yet. | — |
| 2026-11-17 | Universe rule v1: entry on first observed day with market cap ≥ $1M and liquidity ≥ $50K (sum over pairs where the token is base); quote assets excluded; entries never removed. Observed from our own snapshots from 2026-11-17. | SPEC §5.2. No free source publishes liquidity history, so the pre-2026-11-17 backfill will be a separate, labelled version built from Dune. |
| 2026-11-17 | Trade-level source changed from Dune to BigQuery public Solana data, Helius, Alchemy, public EVM RPCs and GeckoTerminal trades. | Dune has no free API plan. No indicator is published yet, so no history is affected. |
| 2026-11-17 | BNB Chain deferred: no longer ingested, and excluded from the universe and all reads. 45 BNB universe entries published earlier the same day stay stored (append-only) but are not read. | Scope decision by Arthur. |
| 2026-11-17 | Robinhood Chain swaps come from the official public RPC (`rpc.mainnet.chain.robinhood.com`), which returned a full day of logs for one pool in under a second. Alchemy is the fallback. | Alchemy's free plan limits `eth_getLogs` to 10 blocks, and Robinhood produces about 10 blocks a second. |
| 2026-11-17 | Chain Rotation Monitor formula `0-raw` (DefiLlama total DEX volume) computed and backtested 2023-09 to 2026-11. Fails its drop rule: shares mean-revert, and Leading underperforms Lagging over 14 days. Stored as description only; not displayed. See `docs/validation/chain_rotation_0-raw.md`. | First indicator through the shared harness. |
| 2026-11-17 | Organic filter v1 for EVM swaps (atomic arb, sandwich, same-block round trip, high frequency at more than 5 swaps per minute, BOT/MM). First measurement: 57% of Robinhood universe-pool USD volume is organic. See `docs/validation/organic_filter_v1.md`. | SPEC §5.5; N was unspecified. |
| 2026-11-17 | Trench Regime Activity formula `0-raw` (deflated DefiLlama volume, TEHscreener active wallets) backtested 2023-07 to 2026-11. Fails its drop rule and the stability test. Stored as description only. See `docs/validation/trench_activity_0-raw.md`. | Shared harness. |
| 2026-11-18 | **Correction.** The organic-filter measurement of 2026-11-17 overstated automated flow (reported ~80% of swaps, 43% of USD). Robinhood's RPC returns zero log timestamps, so the high-frequency rule saw all swaps as simultaneous. Block timestamps are now resolved from blocks, zero timestamps are treated as missing, and the filter refuses untimed swaps. Corrected: 54% of swaps and 83% of USD volume are organic. No published indicator used this measurement. | Bug found while building the Launchpad Scorecard. |
| 2026-11-18 | Launchpad Scorecard inputs v0 for Long.xyz: per-launch outcomes from on-chain launch, pool and swap events (`lp_launch_outcomes`). First cohort: 129 launches from 13 creators, 2 with real early demand, none reached $100K. See `docs/validation/launchpad_long_cohort_2026-11-10.md`. | SPEC §6.3. |
| 2026-11-19 | Launchpad Scorecard formula 0: daily UTC cohorts for Long.xyz and PonsFamily, shared outcome scoring, beta-binomial shrinkage, LQS. First cohort (2026-11-11) published with `validated: false`; LQS is not meaningful with two pads and is not to be displayed as a ranking yet. See `docs/validation/launchpad_scorecard_2026-11-11.md`. | SPEC §6.3. |
| 2026-11-19 | Data policy: the site is a private tool for Arthur. Scraping is allowed, including Sparsity and GMGN, at polite rates with raw responses cached. Spending stays at $0. | Decision by Arthur. |
| 2026-11-19 | Indicator batch formula 0: Sentiment (mSOPR, FIFO within window), Retail Flow Desk (market consumer share; Solana token flags from GMGN app tags), Cohort Flow (Solana, GMGN tags and smart-wallet ranks), cost-basis map and partial Quality × Flow (GMGN holders), Bottom Probability eligibility, organic ratio, meme perp positioning (Hyperliquid), net capital inflow (DefiLlama stablecoins), serial-deployer concentration and Trench PnL, Solana urgency index.
